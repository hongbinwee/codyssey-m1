# M1-1 작업 지침

이 파일은 `M1-1/`에만 적용한다. 루트 작업공간 지침이 제공된 환경에서는 그 규칙도 함께 따른다.

## 범위

- 이 폴더의 미션은 「AI 데이터 분석: 데이터 기반 트렌드 분석」이다. 이 채팅의 후속 작업은 `M1-1`에 한정한다.
- `M1-2`는 다른 채팅에서 진행한다. 사용자가 명시적으로 요청하지 않는 한 그 폴더를 열람·분석·수정하거나 Git 작업에 포함하지 않는다.
- 기존 산출물을 먼저 읽고 필요한 부분만 수정한다. 여러 파일을 바꿀 때는 루트 규칙에 따라 Spec을 먼저 작성한다.

## 데이터와 분석

- 공식 출처는 [서울 열린데이터광장 OA-12921](https://data.seoul.go.kr/dataList/OA-12921/F/1/datasetView.do)이다. 분석 대상은 서울교통공사 관할 1~8호선의 2025년 일별 승차+하차 합계다.
- 공식 CSV는 `data/raw/서울교통공사_역별 일별 시간대별 승하차인원_20251231.csv`에 원본 그대로 둔다. 임의 데이터나 이전 연도 파일을 공식 원본 대신 사용하지 않는다.
- `scripts/prepare_data.py`가 만든 `data/processed/seoul_metro_daily_2025.csv`를 분석 입력으로 사용한다. 원본의 완전 빈 행만 제외하며, 데이터 행의 결측·숫자 오류·음수·중복·날짜 또는 역별 승하차 누락을 조용히 보정하지 않는다.
- 극단값은 원본 오류의 근거가 없으면 유지한다. 리포트에는 데이터에서 확인한 **관찰**과 원인에 관한 **해석(가설)**을 구분하고, 외부 자료가 없는 원인을 확정하지 않는다.
- `REPORT.md`의 수치와 인사이트는 실제 원본에서 재계산한 결과에 맞춘다. 그래프 4개와 리포트 이미지 링크도 함께 확인한다.

## 실행과 제출

- `M1-1/`에서 `python run_all.py`로 전처리와 그래프를 재생성한다. Notebook이나 대시보드를 수정했다면 해당 실행도 확인하고, 실행하지 못한 항목은 검증 완료로 표시하지 않는다.
- `README.md`, `REPORT.md`, `analysis.ipynb`, `SUBMISSION_CHECKLIST.md`의 설명과 실행 결과를 일치시킨다.
- 원본·가공 CSV, `.venv/`, 캐시, 비밀값은 Git에 넣지 않는다. Git에 반영할 때는 `M1-1/` 경로만 선별하고, 공식 데이터의 이용 조건은 재배포 전에 다시 확인한다.
