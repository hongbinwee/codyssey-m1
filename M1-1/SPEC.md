# M1-1 검증·수정 Spec

## 목표와 범위

서울 열린데이터광장 `OA-12921`의 2025년 공식 CSV에서 서울교통공사 관할 1~8호선의 일별 승차+하차 합계를 만들고, 기존 4개 분석 질문·그래프·리포트·노트북·대시보드를 재현 가능하게 검증한다. 기존 구조와 코드의 의도를 유지하며 확인된 결함만 고친다.

## 원본 확인 기준

- 파일: `서울교통공사_역별 일별 시간대별 승하차인원_20251231.csv`
- 원본의 모든 필드가 빈 행만 제거한다. 필드 일부가 빈 데이터 행은 실패로 처리한다.
- `수송일자`, `호선`, `역번호`, `역명`, `승하차구분`과 20개 시간대 컬럼을 확인한다.
- 2025년 각 날짜의 역별 승차·하차 쌍, 숫자 변환, 음수, 중복, 날짜 누락을 검사한다.
- 원본/가공 CSV는 Git에서 제외하고 공식 출처와 이용 조건을 문서화한다.

## 실행 계획

1. 기존 파일과 공식 원본을 비교하고 위험한 가정을 확인한다.
2. `prepare_data.py`에서 잘못된 파일 선택·컬럼 탐지·결측치 0 대체를 막고, 검증을 통과한 데이터만 저장한다.
3. `analyze.py`, `analysis.ipynb`, `app.py`, `run_all.py`를 실제 처리 데이터와 4개 분석 질문에 맞춰 좁게 수정한다.
4. 공식 원본으로 전처리·그래프·노트북·대시보드를 실행하고 핵심 수치를 독립 계산과 대조한다.
5. `REPORT.md`, `README.md`, 데이터 안내, `SUBMISSION_CHECKLIST.md`를 실행 결과와 일치시키고 최종 검수한다.

## 완료 판정

- 공식 원본에서 2025년의 365개 일별 양수 합계가 생성되고 날짜·역·승하차·시간대 검증을 통과한다.
- 7일/30일 이동평균, 전일 대비 변화율, 요일별·월별 평균과 그래프 4개가 실제 결과를 반영한다.
- 리포트의 수치·이미지·관찰/해석·한계·AI 사용 로그가 검증 결과와 일치한다.
- 노트북이 처음부터 끝까지 실행되고 대시보드가 정상 시작된다.
- 원본과 처리 CSV가 Git 추적 대상이 아니다.
