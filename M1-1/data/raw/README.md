# 공식 원본 데이터 넣는 곳

이 폴더에는 **서울 열린데이터광장의 공식 원본 CSV**를 넣습니다.

## 대상 데이터

- 데이터셋: `서울교통공사_역별 일별 시간대별 승하차인원 정보`
- 공식 데이터셋 ID: `OA-12921`
- 2025 파일명: `서울교통공사_역별 일별 시간대별 승하차인원_20251231.csv`
- 공식 페이지: https://data.seoul.go.kr/dataList/OA-12921/F/1/datasetView.do
- 제공기관: 서울교통공사
- 분석 범위: 서울교통공사 관할 1~8호선, 2025-01-01 ~ 2025-12-31
- 이용허락범위: 공식 페이지 표시 기준 공공누리 3유형(출처표시 + 변경금지)

공식 페이지의 **파일내려받기** 표에서 첫 번째 2025년 CSV를 선택해 이 폴더에
위 파일명 그대로 저장합니다. 2026-09-26에 내려받은 파일의 SHA-256은
`99591265DAF498015499F03913CD3253A57C3FF976AE182F9C4AF89FCCA4E5BA`입니다.
공식 파일이 수정되면 해시가 달라질 수 있으므로 그때는 날짜와 변경 내용을 확인합니다.

## 왜 원본 CSV를 Git 저장소에 포함하지 않았나?

공식 페이지에 표시된 이용허락범위가 **공공누리 제3유형(출처표시 + 변경금지)**이므로,
이 저장소는 원본 또는 가공 CSV를 재배포하지 않고 **다운로드 방법과 재현 코드**를 제공합니다.

다운로드한 원본 파일을 이 폴더에 그대로 두고 아래를 실행하세요.

```bash
python scripts/prepare_data.py
```

그러면 다음 파일이 로컬에서 생성됩니다.

```text
data/processed/seoul_metro_daily_2025.csv
```

> 주의: 공식 사이트의 다운로드 화면/로그인 정책은 변경될 수 있습니다.
