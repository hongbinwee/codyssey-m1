# 2025 서울 지하철 이용량 시계열 분석

서울교통공사 관할 1~8호선의 **2025년 공식 역별·일별·시간대별 승하차 원본 데이터**를
일별 총 이용량으로 집계한 뒤 이동평균, 변화율, 요일/월별 패턴을 분석하는 프로젝트입니다.

## 분석 질문

1. 2025년 이용량의 장·단기 추세는 어떻게 나타나는가?
2. 평일과 주말 및 각 요일의 평균 이용량은 얼마나 다른가?
3. 급격한 증가·감소가 발생한 날짜는 언제인가?
4. 월별 평균 이용량에는 어떤 차이가 있는가?

## 공식 데이터

- 데이터셋: 서울교통공사_역별 일별 시간대별 승하차인원 정보
- 서울 열린데이터광장 ID: `OA-12921`
- 2025 원본 파일명: `서울교통공사_역별 일별 시간대별 승하차인원_20251231.csv`
- 공식 페이지: https://data.seoul.go.kr/dataList/OA-12921/F/1/datasetView.do
- 제공기관: 서울교통공사
- 관할: 서울교통공사 1~8호선 구간
- 이용허락범위: 공식 페이지 표시 기준 **공공누리 3유형(출처표시 + 변경금지)**

2026-09-26 내려받아 확인한 원본에는 `수송일자`, `호선`, `역번호`, `역명`,
`승하차구분`(`승차`/`하차`) 및 `06시이전`~`24시이후`의 20개 시간대 인원이 있습니다.
실제 데이터 행은 199,290개이며 파일 끝의 완전 빈 행 134개는 전처리에서 제외합니다.
공식 파일의 SHA-256은 `99591265DAF498015499F03913CD3253A57C3FF976AE182F9C4AF89FCCA4E5BA`입니다.

## 실행 방법

### 1. 환경 설치

`M1-1` 디렉터리에서 실행합니다. 검증에 사용한 Python 버전은 3.12입니다.

```bash
python -m venv .venv
```

Windows:

```bash
.venv\Scripts\activate
```

macOS/Linux:

```bash
source .venv/bin/activate
```

```bash
pip install -r requirements.txt
```

### 2. 공식 원본 다운로드

위 공식 페이지에서 **파일내려받기** 표의 첫 번째 2025년 CSV 파일을 내려받습니다.
다른 연도 파일은 전처리에 사용하지 않습니다.

```text
서울교통공사_역별 일별 시간대별 승하차인원_20251231.csv
```

그리고 `M1-1` 기준 다음 위치에 **원본 그대로** 둡니다.

```text
data/raw/
```

### 3. 전처리

```bash
python scripts/prepare_data.py
```

결과:

```text
data/processed/seoul_metro_daily_2025.csv
```

### 4. 그래프 재생성

```bash
python scripts/analyze.py
```

또는 전처리부터 한 번에:

```bash
python run_all.py
```

### 5. Notebook

```bash
jupyter notebook analysis.ipynb
```

### 6. Streamlit 보너스

```bash
streamlit run app.py
```

## 전처리 로직

원본 각 행의 모든 시간대 인원을 합산합니다.

```text
행 총합 = 06시이전 + 06-07시간대 + ... + 23-24시간대 + 24시이후
```

그 후 날짜별로 모든 역과 승·하차 행을 합산합니다.

```text
일별 총 이용량 = 날짜별 모든 행의 시간대 인원 합계
```

전처리 스크립트는 필수 컬럼, 숫자형·음수·중복, 매일 역별 승차/하차 쌍과 날짜 누락을 검사합니다.
검증에 통과해야 2025년 365개의 시계열 포인트를 저장합니다.

## 데이터 품질 및 이상치 원칙

공휴일, 연휴, 행사 등의 영향으로 이용량이 낮거나 높은 값은
실제 현상일 수 있으므로 자동으로 삭제하지 않습니다.

`이상치 = 제거 대상`이 아니라 `추가 확인이 필요한 관찰값`으로 취급합니다.

## 라이선스/재현성

공식 페이지의 공공누리 3유형(출처표시 + 변경금지) 표시를 존중하기 위해 원본 및 가공 CSV는 Git 저장소에 재배포하지 않습니다.
대신 공식 다운로드 경로와 자동 전처리 코드를 제공하여 동일 분석을 재현할 수 있게 했습니다.

분석 결과에 외부 사건의 원인을 연결할 때는 별도 자료로 검증해야 합니다.
